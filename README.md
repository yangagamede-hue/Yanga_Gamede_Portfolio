# My Digital Showcase
webpage link - https://yanga-gamede-portfolio.lovable.app

Role & Goal:

Act as an expert full-stack developer and UI/UX designer. Build a modern, highly responsive, and visually impressive Personal Portfolio Website designed to showcase my profile to potential employers for internships and full-time job opportunities.

1. Layout & Core Structure

Create a clean, single-page or seamless multi-section layout featuring a persistent, sticky navigation header (with quick-scroll links and a theme toggle for dark/light mode) and a footer. The site must contain the following sections:

Hero / Home Section:

Professional intro header: Full Name, Professional Title / Tagline (e.g., Full-Stack Developer | Problem Solver).

A short, high-impact elevator pitch (2–3 sentences).

Call-to-Action (CTA) buttons: "View Projects", "Contact Me", and "Download CV" (with a download trigger).

Placeholder for a high-quality professional headshot/avatar.

About Me Section:

Narrative overview covering my background, passion for technology, career goals, and core values.

Skills Section:

Technical Skills: Categorized layout (e.g., Languages, Frameworks, Tools, Databases) using sleek visual badges/tags.

Soft Skills: Interpersonal and teamwork strengths displayed cleanly using icons or card grids.

Projects Section (Featured Work):

Display at least 3 project cards in a grid layout.

Each project card must include:

Project Title & Short Summary

Key Features list

Technology stack badges used (e.g., React, TypeScript, Tailwind)

Interactive buttons: "Live Demo" and "GitHub Code" links.

Education & Certifications Section:

Education: Timeline or card layout showing Degree, University/Institution name, and Graduation Year.

Certifications: Grid or list of professional certificates with issuing organization, date, and credential link placeholders.

Work Experience Section:

Timeline design displaying job title, company name, dates, and key achievements/bullet points. Include a fallback view for "Academic & Hands-on Project Experience" if formal employment is pending.

Contact Section:

Functional contact form (Name, Email, Subject, Message) with client-side validation and success feedback.

Direct contact detail badges: Email address, GitHub profile link, LinkedIn profile link.

2. Design & UI/UX Guidelines

Design System: Sleek, modern, tech-focused aesthetic (minimalist with subtle gradients, clean typography like Inter or Plus Jakarta Sans, and smooth hover effects on cards and buttons).

Color Palette: Professional dark/light mode toggle with a primary accent color (e.g., Deep Indigo/Electric Blue) for key buttons and highlights.

Responsiveness: Fully mobile-first design. Ensure seamless scaling and layout adjustments across Mobile, Tablet, and Desktop screens. Mobile menu should feature a smooth slide-out or dropdown navigation.

3. Technical Architecture

Use React, TypeScript, and Tailwind CSS.

Use Lucide Icons (or standard accessible icon sets) for section headings, social media, and skill badges.

Code should be modular, clean, and well-commented so I can easily explain and customize the components later.
